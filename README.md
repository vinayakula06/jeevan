# Jeevan AI Postal Service

**Jeevan AI Postal Service** is an intelligent postal delivery tracking and routing system developed as part of a college project. It automates package tracking, optimizes delivery routes, and updates delivery status at each step using QR code scanning and geolocation services. The system uses a trained deep learning model and real-world delivery data to enable accurate and efficient delivery tracking.

---

## 🚀 Project Overview

Jeevan AI Postal Service provides:

- Automated tracking of consignments using QR code scans at each postal hub.
- Dynamic nearest post office lookup using geographic coordinates for optimized routing.
- Real-time status updates and delivery confirmations at every stage.
- Intuitive user interface to view consignment status and next delivery step.

The model used for detecting delivery stages and predicting next stops is **trained**, and real delivery data is utilized as part of the system’s logic.

##  Features

- **Consignment Creation:** Create and track consignments with sender and receiver details.
- **QR Code Integration:** Scan QR codes at every handoff location to update delivery status.
- **Route Optimization:** Determine the nearest post office for delivery using geolocation and routing logic.
- **Delivery Confirmation:** Automatically confirm delivery when the final QR scan is completed.
- **Status Interface:** View real-time tracking data including current location and next stop.

## 🛠 Tech Stack

The project uses the following technologies:

- **Backend:** Python, Django, REST APIs  
- **Routing & Geolocation:** OSRM (Open Source Routing Machine), Geolocation Services  
- **QR Code Handling:** OpenCV, QR Code Integration  
- **Database:** MySQL  
- **Frontend:** HTML, CSS, JavaScript
